Custom Raspberry Pi image for NAS and PXE server

The goal is to create a custom Linux distro to run only a NAS and a PXE server. I want the NAS to store my files locally and the PXE server so I can quickly iterate and experiment with my Dell Wyse 5070 without having to reflash a USB stick every time I change the image.

I feel that using stock distributions on a Raspberry Pi, especially the ones with less RAM (e.g RPi Zero with 512 MB) is a bit resource intensive. Besides that, although I have never experience these kinds of problems myself, I know the SD cards eventually fail if used constantly due to the nature of the flash memory.

I want to use Buildroot to create a custom Linux distribution. The main goals are:

  • Using a Raspberry Pi 4 Model B with 2 GB of RAM
  • Running everything from RAM
  • Tailor everything for the exact application - a NAS + PXE server, adding only necessary packages and kernel features

With that, I hope to achieve faster boot times, a more responsive system, and very low RAM usage. More importantly, I hope to learn more about kernel internals.
